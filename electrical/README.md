# Electrical

Electrical design files for power, control, sensors, and communication.

Suggested layout:
- `source/`: schematic and PCB source projects.
- `export/`: generated PDFs and review exports.
- `bom/`: component lists and procurement tables.
- `gerber/`: manufacturing outputs.
- `wiring/`: harness, connector, and pinout documents.
- `test/`: bring-up and validation records.
- `archive/`: approved release snapshots.
