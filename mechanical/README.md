# Mechanical

Mechanical design files for the AGV and manipulator platform.

Suggested layout:
- `source/`: native CAD or mechanical design source files.
- `export/`: STEP, PDF, DXF, and review exports.
- `bom/`: bills of materials.
- `drawings/`: 2D drawings, annotations, and review prints.
- `assembly/`: assembly notes and procedures.
- `test/`: fit, load, and verification records.
- `archive/`: approved release snapshots.
