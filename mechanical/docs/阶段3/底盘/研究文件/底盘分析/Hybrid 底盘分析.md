# 结论（先看结论）

- **结论**：双麦轮 + 差速双轮（下文简称“Hybrid”）通常**可以满足大多数“灵活优先且要放机械臂/载物台”的室内平台需求**，并比全麦轮成本更低、实现更简单。但要做到稳定、可控、能爬坡且不易翻覆，需要按下面的要点去配套电机扭矩、驱动和机械布局。
    
- **推荐做法（性价比最高）**：把**差速双轮作为主牵引轮（驱动 & 闭环）**，把**麦轮做为电动助力或被动承重/导向轮**。驱动板推荐一对支持闭环的中功率驱动（如 Cytron 类或国产 CAN 智能小板），麦轮若电动可选小功率驱动或用被动滚轮以节约成本。

# 一、为什么 Hybrid 可行（优缺点概览）

优点

- 成本比全四麦/四全向低（只需为两只麦轮或两只差速轮配较强驱动）。
    s
- 仍能获得比纯差速车更好的机动性：结合差速转向 + 麦轮侧向滑行/辅助，可实现小幅横移与更灵活的定位。
    
- 控制复杂度低于全麦轮系统（不需要全向动力学逆解），调试量小。
    

缺点 / 风险

- 并非“完全全向” —— 原地平移能力受限（取决于麦轮是否主动驱动及其位置/摩擦）。
    
- 麦轮若为被动，则横向机动性靠差速/摆动和滑动实现，精度与效率较差。
    
- 侧向承载与横向效率比全麦差，需要更强电机或更大轮径来补偿。
    
- 控制算法需把主驱动和麦轮（如果有电驱）做协调，包含转向和侧滑补偿（IMU/里程计融合）。

# 二、推荐的机械/布局原则（务必遵守）

1. **差速轮做主牵引，放在靠后或靠前对称位置**（两轮间有合理轴距），以保证推进力与转向能力。
    
2. **麦轮放在车的两侧中前部/中后部，尽量靠近质心高度**，以便在需要横移/微调时产生侧向力矩。
    
3. **机械臂基座放在底盘几何中心或略靠后**（避免前翻）。若臂必需放前端，则加后配重或延长轴距。
    
4. **给差速轮装编码器，做闭环速度控制**；若麦轮电驱，也应带编码器，用于协同控制或直接做状态估计。
    
5. **增加IMU + 轮速（里程计）融合**，补偿麦轮滑动误差。

# 三、量化扭矩与爬坡校核（逐位算式，示例：用我们之前常用的示例车重）

> 我用之前示例值：底盘/结构12 kg + 机械臂4 kg + 载物2 kg → **总质量 18 kg**，轮半径 0.05 m（100 mm 轮），目标最大加速度 0.5 m/s²，最大爬坡 10°。你可以把你真实数据代入相同公式。

### 基本数值

- (m_{tot} = 18\ \text{kg}).
    
- (g = 9.81\ \text{m/s}^2.)
    
- 轮半径 (r = 0.05\ \text{m}.)
    
- 目标加速度 (a = 0.5\ \text{m/s}^2.)
    

#### 1) 加速所需总牵引力

(F = m_{tot} \cdot a).  
逐位算：  
(F = 18 \times 0.5 = 9.0\ \text{N}.)

如果**差速双轮承担主要牵引**（两轮提供力），则每驱动轮需要的牵引力为：  
(F_{wheel} = F / 2 = 9.0 / 2 = 4.5\ \text{N}.)

对应轮边扭矩：  
(T_{wheel} = F_{wheel} \cdot r = 4.5 \times 0.05 = 0.225\ \text{N·m}.)

这是理想值（不计摩擦、效率损失）。考虑轮/地摩擦、麦轮横向损失、启动电流与安全裕度，**常用安全系数 4~6**。  
取 **×5**：推荐每主驱动轮实际目标扭矩 ≈ (0.225 \times 5 = 1.125\ \text{N·m}.)

结论（加速项）：**每主驱动轮至少 1.1 N·m**，实务上建议 **2~4 N·m** 以便余量。

#### 2) 爬坡 10° 的牵引需求

总重力：(m_{tot} \cdot g).  
逐步算：  
(18 \times 9.81 = 176.58\ \text{N}.)

沿坡分力：(F_{slope} = 176.58 \times \sin 10^\circ.)  
先得 (\sin 10^\circ \approx 0.17364817766.)  
逐步算：  
(F_{slope} = 176.58 \times 0.17364817766 \approx 30.674\ \text{N}.)

若差速双轮承担牵引（2 个轮），每轮牵引力：  
(F_{wheel,slope} = 30.674 / 2 = 15.337\ \text{N}.)

对应扭矩：  
(T_{wheel,slope} = 15.337 \times 0.05 = 0.76685\ \text{N·m}.)

考虑摩擦与效率，取安全系数 4：  
推荐扭矩 ≈ (0.76685 \times 4 = 3.0674\ \text{N·m}.)

结论（爬坡项）：**每主驱动轮至少 ~3.1 N·m**，为保险建议 **3–6 N·m**。

> 综合加速与爬坡：以爬坡需求更苛刻，建议主驱动轮设计目标 **≥ 3 N·m**（减速后输出）。这和我们之前给出的“单轮 2–6 N·m”在同一量级。

#### 3) 麦轮的角色与规格

- 如果**麦轮为被动**：不承担主要纵向牵引，只承受径向/侧向载荷；需满足静态承重（每轮承载 ≈ 总质量/4 = 18/4 = 4.5 kg 静载，但要考虑动态冲击，推荐额定承载 ≥ 15–30 kg/轮）。
    
- 如果**麦轮为主动驱动（小电机）**：它们可以在需要做横向微调或减少差速轮滑动时提供辅助推力，但扭矩可比主驱动小（例如 0.5–1.5 N·m），这样成本增加小但机动性明显改善。

# 四、控制与驱动板匹配建议（实用、性价比路线）

1. **主驱动（差速两轮）**
    
    - 电机选择：24V 编码电机 + 行星减速，使轮边扭矩 ≥ 3 N·m。举例：电机额定扭矩×减速比 ≥ 3 N·m。
        
    - 驱动板：要支持闭环速度控制 & 编码器输入。性价比推荐：**Cytron MD13S 类（中等功率）** 或 高可靠的 **BTS7960+外部闭环控制**（若你能自己实现闭环）。科研/更好集成则用 **VESC/ODrive（若无刷）或 CAN 智能驱动**。
        
    - 编码器：每主轮至少 360–1024 CPR（或更高）用于稳定里程计 + 闭环速度。
        
2. **麦轮（被动或低功率驱动）**
    
    - 若**被动**：选承载 ≥ 30 kg/轮 的 100–152 mm 麦轮，轴孔需匹配底盘/联轴器。被动省钱但横向动作效率差。
        
    - 若**主动**（推荐若预算允许）：选择低速高扭矩的小编码电机（目标轮边扭矩 0.5–1.5 N·m），驱动由小型 PWM 驱动或结合主控制器的低功率通道控制。麦轮主动后能显著提高横向/微位移精度。
        
3. **驱动板数量与类型（淘宝匹配建议）**
    
    - 主驱动（2 路）：可用 **2 × Cytron MD13S**（带编码器输入，约中等价位），或 **2 × BTS7960 + MCU（做闭环）**（最便宜但开发量大）。
        
    - 麦轮若主动（2 路）: 选 **低功率集成驱动+编码接口**（例如小型直流带编码驱动模块）。
        
    - 若要统一总线方便调试与 ROS2，选 **双通道 CAN 智能驱动板**（若预算允许）。

# 五、成本-性能折中建议（三档）

1. **低成本档（预算敏感）**
    
    - 主驱动：24V 电机 + BTS7960（43A）×2（开环或简单闭环）
        
    - 麦轮：被动 100mm 麦轮
        
    - 控制：MCU（STM32/Arduino）做速度 PID
        
    - 适用：演示 / 教学 / 轻载短时任务
        
2. **性价比档（推荐）**
    
    - 主驱动：24V 编码电机 + Cytron MD13S 或 MD10C ×2（支持编码器闭环）
        
    - 麦轮：主动（小电机）或高承载被动轮
        
    - 控制：ROS/嵌入式 + IMU 融合，精度良好，调试友好
        
3. **高性能档（科研/商用）**
    
    - 主驱动：无刷编码电机 + VESC/ODrive（CAN）或商用 CAN 智能驱动 ×2
        
    - 麦轮：主动并带编码回授
        
    - 控制：高性能控制器（实时），完整里程计/IMU/LiDAR 融合

# 六、稳定性 / 翻覆风险校核（简要提醒）

- 一定要做**前后翻覆力矩校核**（见上次我给你的详细算式）。若臂和载物偏前，优先**增大轴距**或**后置配重**。
    
- 在Hybrid方案中，麦轮位置会影响侧向支撑点，放置要使载荷分布均匀，避免在臂伸出时产生大的翻覆矩。

# 七、控制实现要点（避免你常见的坑）

- **编码器一定要带差分/高 CPR**（主驱动），以保证闭环稳定。
    
- **IMU + 里程计融合**：麦轮滑动大时仅靠里程计会误差累积，需融合IMU/视觉。
    
- **PID 调参**：差速车的内外轮在转弯时速度差异大，PID 需在负载变化下鲁棒。
    
- **刹车或电机制动**：机械臂抓取重物时需要平台稳定，建议驱动带电机制动或减速器带制动器。
