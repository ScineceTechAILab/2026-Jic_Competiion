# 1) 前提与公式（重申）

- g = 9.81 m/s²。
    
- 关节命名：**基座 (Joint1)**、**肩（Joint2）**、**肘（Joint3）**（肘在 L2 处）。
    
- 目标姿态：**最不利姿态（两节臂水平伸直）**，用于求最大静态重力扭矩。
    
- 力矩计算公式（对某质量 m，距离 r）： M=m⋅g⋅rM = m \cdot g \cdot rM=m⋅g⋅r。
    
- 对复合系统把各质量到关节的力矩叠加。
    
- 安全系数取 **SF = 2.0**（覆盖惯性、加速、冲击与热能力）。
    

# 2) 逐步、逐位计算（数字逐步展示）

先计算常量：

- g = 9.81 N/kg
    

各长度：

- L1 = 0.18 m
    
- L2 = 0.12 m
    

各质量：

- m_payload = 3.0 kg
    
- m_tool = 0.2 kg
    
- m_link2 = 0.5 kg
    
- m_link1 = 0.8 kg
    

## 肘关节（Joint3）—— 关于肘的静态扭矩

肘关节上要克服的重力项为：末端质量与手爪在 L2 处，以及前臂（link2）自重在 L2/2 处。

计算步：

1. 末端合质量 = m_payload + m_tool = 3.0 + 0.2 = **3.2 kg**
    
2. 对末端合质量产生的力矩：3.2 × g × L2
    
    - 3.2 × 9.81 = 31.392 N
        
    - 31.392 × 0.12 = 3.76704 N·m
        
3. link2 的自重力矩：m_link2 × g × (L2/2)
    
    - L2/2 = 0.12 / 2 = 0.06 m
        
    - m_link2 × g = 0.5 × 9.81 = 4.905 N
        
    - 4.905 × 0.06 = 0.2943 N·m
        
4. 肘静态总力矩 = 3.76704 + 0.2943 = **4.06134 N·m**
    

设计（含 SF=2.0）：

- 肘设计扭矩 = 4.06134 × 2.0 = **8.12268 N·m**
    

---

## 肩关节（Joint2）—— 关于肩的静态扭矩

肩关节需支撑整个前臂和末端物体，距肩的臂长对各质量为：

- 末端合质量作用臂：L1 + L2 = 0.18 + 0.12 = **0.30 m**
    
- link2 自重作用臂：L1 + L2/2 = 0.18 + 0.06 = **0.24 m**
    
- link1 自重作用臂：L1/2 = 0.18 / 2 = **0.09 m**
    

计算步：

1. 末端合质量产生的矩：3.2 × 9.81 × 0.30
    
    - 3.2 × 9.81 = 31.392 N
        
    - 31.392 × 0.30 = 9.4176 N·m
        
2. link2 的矩：0.5 × 9.81 × 0.24
    
    - 0.5 × 9.81 = 4.905 N
        
    - 4.905 × 0.24 = 1.1772 N·m
        
3. link1 的矩：0.8 × 9.81 × 0.09
    
    - 0.8 × 9.81 = 7.848 N
        
    - 7.848 × 0.09 = 0.70632 N·m
        
4. 肩静态总力矩 = 9.4176 + 1.1772 + 0.70632 = **11.30112 N·m**
    

设计（含 SF=2.0）：

- 肩设计扭矩 = 11.30112 × 2.0 = **22.60224 N·m**

## 基座（Joint1）

- 若基座只需克服重力分量（水平姿态），其重力矩与肩相同（在简单重力计算里）：**静态 11.30112 N·m，设计 22.60224 N·m**。

# 5) 其它实用建议（立即可用）

1. **如果你的动作速度不高**（慢速搬运/示教再现），SF=2 已经非常保守；若速度高、加速度大，建议把 SF 提高或做动态惯性计算（下文可做）。
    
2. **核对连续值**：购买时要求厂商提供**连续额定扭矩**和**温升曲线**（不要只看峰值或堵转扭矩）。
    
3. **电源与散热**：肩/基座可能需要 12V（或更高）与较大瞬时电流，设计电源时预留足够峰值能力与散热方案。
