# 编码电机

编码电机是现代机器人和自动化系统中常用的驱动元件，具有高精度、高效率和良好的控制性能。以下是编码电机的一些关键特性和选型建议：

## 指标介绍










### 线数



你问的“**线数**”，在电机编码器里是一个非常核心的指标。它常见的英文表述是 **PPR（Pulse Per Revolution，转一圈输出的脉冲数）**，有时也叫 **CPR（Counts Per Revolution）**。

---

#### 1. 线数的含义

* **定义**：编码器随轴旋转，每转一圈输出多少个电脉冲。
* **举例**：

  * 100 线编码器 → 每转一圈产生 100 个脉冲。
  * 如果是 A、B 两路正交输出，实际可以区分出 4 倍（400 个计数/圈）。
* **作用**：线数越高，分辨率越高，电机位置与速度检测就越精细。

---

#### 2. 霍尔编码器 vs GMR 编码器

| 特征         | 霍尔编码器                  | GMR 编码器                       |
| ---------- | ---------------------- | ----------------------------- |
| **原理**     | 霍尔效应，检测磁场变化            | 巨磁阻效应（磁电阻变化更敏感）               |
| **常见线数范围** | 典型低分辨率：12、48、64 线等     | 高分辨率：256、512、1024 甚至几千线       |
| **精度**     | 较低，只能用于换相或粗略测速         | 高，适合精确测速和位置控制                 |
| **成本**     | 低                      | 略高                            |
| **输出形式**   | A/B 路方波（可能附带 Z 相）      | A/B 路方波（可能附带 Z 相），但频率更高，边沿更密集 |
| **适用场景**   | 电机换相、简单测速（比如风扇电机、低端小车） | 高精度运动控制、伺服、机器人底盘              |

---

#### 3. “线数”在实际选型中的作用

* **低线数（<100）**：只能做粗测速 / 换相。比如小车简单前进、倒车。
* **中线数（100~500）**：能做中等精度闭环控制，适合差速/麦轮小车。
* **高线数（1000 以上）**：适合需要高精度定位的伺服、机械臂关节或高端底盘。

---

📌 **总结一句话**：

> “线数”就是编码器的分辨率，数值越大，位置/速度反馈越精细。霍尔编码器线数低，多用于粗控制；GMR 编码器线数高，更适合机器人底盘的精准运动控制。

## 参数明确

1. **电压**：确认电机额定电压，确保与驱动器和电源匹配
2. **转速**：根据底盘设计时速和轮径，计算所需轮边转速，再结合减速比选择电机空载转速。
3. **扭矩**：计算所需轮边扭矩，结合减速比和效率，选择电机额定扭矩和峰值扭矩。
4. **编码器**：根据控制精度需求，选择合适分辨率的增量式编码器（如 500 CPR 或 1000 CPR）。
5. **轴径与安装**：确认电机轴径（如 8mm D 轴）和法兰尺寸，确保与麦轮或联轴器匹配。
6. **电流**：计算电机额定电流和峰值电流，确保驱动板能提供足够的电流。
7. **功率**：根据转速和扭矩计算电机功率，选择合适功率等级的电机。
8. **寿命与散热**：选择寿命长、散热性能好的电机，避免过热影响寿命。
9. **防护等级**：根据使用环境选择防护等级，户外或多尘环境优先考虑防水防尘设计。
10. **控制接口**：确认编码器和电机控制接口，确保与驱动板兼容。

## 参数计算

1. **轮边扭矩计算**：

   $$
   {wheel} = \frac{(M_{total} \times g) \times r}{N}
   $$

   其中，$M_{total}$ 是机器人总质量（kg），$g$ 是重力加速度（9.81\,\mathrm{m/s^2}$），$r$ 是轮半径（m），$N$ 是轮子数量。
2. **电机扭矩计算**：

   $$
   {motor} = \frac{T_{wheel}}{Gear\ Ratio \times \eta}
   $$

   其中，$Gear\ Ratio$ 是减速比，$\eta$ 是减速器效率（通常 $0.7$–$0.9$）。
3. **电机转速计算**：

   $$
   M_{motor} = \frac{V_{target} \times 60}{2\pi r \times Gear\ Ratio}
   $$

   其中，$V_{target}$ 是目标速度（m/s）。
4. **电机功率计算**：

   $$
   {motor} = \frac{T_{motor} \times \omega}{9550}
   $$

   其中，$\omega$ 是电机角速度（RPM 转为 rad/s）。
5. **电流计算**：

   $$
   = \frac{P_{motor}}{V_{supply} \times \eta_{motor}}
   $$

   其中，$V_{supply}$ 是电机供电电压，$\eta_{motor}$ 是电机效率（通常 $0.7$–$0.9$）。
6. **编码器分辨率选择**：

   - 速度控制：500–1000 CPR 通常足够。
   - 位置控制：1000 CPR 以上，视精度需求而定。
7. **轴径与安装**：

   - 麦轮尺寸要和电机轴/法兰匹配（轴径、安装孔距）。

   👉 淘宝搜“麦克纳姆轮”，主要看：直径（75mm/100mm/152mm）、额定承重（kg/轮）、轴孔直径（8mm/10mm/12mm）。

   - 轴径：选择合适的轴径以确保与电机轴匹配。
   - 安装孔距：确保安装孔距与电机法兰匹配。

## 选型建议

1. **确定需求**：根据应用场景，明确电机的转速、扭矩和负载要求。
2. **选择编码器类型**：根据精度要求选择适当的编码器类型，如增量型或绝对型编码器。
3. **考虑驱动方式**：根据电机类型选择合适的驱动方式，如PWM调速或FOC控制。
4. **评估环境条件**：考虑工作环境的温度、湿度和防护等级，选择适合的电机型号。
5. **品牌和售后服务**：选择有良好口碑和售后服务的品牌，确保长期稳定运行。

- **入门 / 教育机器人** → 有刷 DC 电机 + 编码器（便宜好控）
- **轻载 / 高效 / 长寿命** → BLDC 电机（工业机器人常用）
- **低速 / 定位精度要求高** → 步进电机（但不太适合高速底盘）
- **工业 / 高性能底盘** → 交流伺服电机（最可靠但最贵）
- **简化结构 / 小车类** → 轮毂电机（但一般只适合轻载）

---

✅ **结论**底盘电机的主流选择基本是：

- **小型/教育**：DC 有刷电机 + 编码器
- **中型/AGV**：BLDC 电机（有时做成轮毂电机）
- **工业/重载**：AC 伺服电机

# 常规舵机

## 舵机选型对比表

| 对比维度               | **PWM 舵机**                        | **UART 舵机**                            | **CAN 舵机**                               |
| ---------------------- | ----------------------------------------- | ---------------------------------------------- | ------------------------------------------------ |
| **控制接口**     | 单根 PWM 信号线（脉宽调制）               | TTL/RS485 串口（UART 通信）                    | CAN 总线（差分信号）                             |
| **接线复杂度**   | 简单（信号 + 电源）                       | 中等（TX/RX + 电源，有时需RS485收发器）        | 复杂（CANH、CANL、电源，需终端电阻）             |
| **控制方式**     | 占空比 / 脉宽对应角度                     | 指令帧，角度/速度/扭矩控制                     | 标准 CAN 帧，支持多种控制模式                    |
| **精度与分辨率** | 低，中等精度（一般 8-12 位）              | 高（命令数字化，分辨率可达 16 位）             | 高（工业级分辨率和控制）                         |
| **反馈能力**     | 基本无反馈（部分高端 PWM 舵机有位置反馈） | 支持角度、速度、电流等反馈                     | 丰富反馈：位置、速度、扭矩、电流、温度、错误状态 |
| **控制对象数量** | 单片机 I/O 数受限，一般几十路以内         | 一条总线上支持多个舵机（需 ID 区分）           | 总线支持多节点（理论 100+，实际数十个常见）      |
| **实时性**       | 高（信号直接对应动作）                    | 中等（取决于波特率和协议效率）                 | 高（CAN 协议优先级仲裁，实时性好）               |
| **抗干扰性**     | 较差（PWM 容易受噪声干扰）                | 中等（UART 受线长和速率限制）                  | 强（差分信号 + CRC 校验）                        |
| **通信距离**     | 短（<1m 推荐）                            | 中（UART TTL <1m，RS485 可达 100m）            | 长（数百米可行，常见 ≤40m）                     |
| **开发难度**     | 低（MCU 定时器即可）                      | 中等（需要协议解析）                           | 高（需要 CAN 控制器和协议栈）                    |
| **典型应用**     | 玩具、入门机器人、简单舵机控制            | 机器人、DIY 舵机系统、教育科研                 | 工业机器人、AGV、机械臂、高可靠应用              |
| **硬件成本**     | ★ 低（几美元起）                         | ★★ 中等（10~30 美元/个常见）                 | ★★★ 高（50~200+ 美元/个常见）                 |
| **系统成本**     | ★ 低（布线简单，MCU 直接驱动）           | ★★ 中等（需额外总线管理，可能需要RS485芯片） | ★★★ 高（CAN收发器、线缆、终端电阻、调试工具） |
| **开发成本**     | ★ 低（快速上手）                         | ★★ 中等（需要协议解析）                      | ★★★ 高（需要掌握 CAN 协议栈和调试）           |

> **注意**：严格来说，**UART 不是天然的总线协议**，但是通过 **单线半双工 + 地址管理** 或 **RS485 扩展**，它能被“总线化”。

---

✅ **成本总结**

- **PWM 舵机** → 硬件和开发都最便宜，但功能最弱。
- **UART 舵机** → 成本和功能折中，科研和中小型机器人常用。
- **CAN 舵机** → 单个舵机和系统搭建都最贵，但扩展性、抗干扰、工业可靠性最佳。
