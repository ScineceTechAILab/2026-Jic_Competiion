## 三、填写规范与核心注意事项

1.  **时效性优先**：会议结束后24小时内完成纪要撰写、审核与分发，确保事项及时落地。
2.  **拒绝流水账**：核心记录**决议、待办、责任人、时限**，不记录无意义的发言细节，客观中立，不添加主观评价。
3.  **权责清晰**：所有待办事项必须明确**唯一第一责任人**，避免多人负责等于无人负责；完成时限精确到日期，验收标准可量化、可核查。
4.  **闭环管理**：下次会议需先复盘上一次纪要的待办事项完成情况，形成“会议-决议-执行-复盘”的完整闭环。
5.  **版本管理**：正式纪要如需修改，需更新版本号，并标注修改内容与原因，避免多版本混乱。

## 四、不同会议类型的适配调整要点

1.  **项目启动会**：侧重项目目标、范围、组织架构、里程碑计划、权责分工、核心管理规则的决议，补充项目整体规划附件。
2.  **需求评审会**：侧重需求范围、验收标准、技术可行性、变更管控规则的决议，补充需求文档、评审意见汇总附件。
3.  **风险/问题复盘会**：侧重问题根因、整改措施、预防机制、责任人的决议，补充根因分析报告、整改计划表。
4.  **里程碑评审会**：侧重阶段交付物验收、目标达成情况、偏差分析、下一阶段准入条件的决议，补充阶段交付物、验收报告。
