# Design Docs Index

This directory is the entry point for all design-related documentation.

## Structure
- `项目规范/`: cross-domain project rules and standards.
- `hardware/mechanical/机械区/`: mechanical design knowledge, stages, and records.
- `hardware/electrical/电路区/`: electrical design knowledge, stages, and records.
- `docs/程序区/`: software architecture, interfaces, and implementation records.
- `项目绘图/`: architecture diagrams and explanatory drawings.
- `项目知识/`: reusable references and technical notes.
- `项目问题/`: architecture gaps, issues, and follow-up items.
- `项目资源/`: links, prompts, and supporting resources.
- `交接区/`: handoff materials and onboarding notes.
