## 🌱 基础打底（Week 0–3）

**目标**：建立对全局架构和接口的理解，不陷入细节。

- **统筹能力**
    
    - 熟悉项目阶段划分（阶段 1–6）
        
    - 明确接口契约：ROS2 topic/action/service 的基本格式及最新特性（如生命周期节点）
        
    - 学会用 `rosbag2` / `rqt_graph` / Foxglove Studio 可视化系统模块流
        
- **算法基础**
    
    - 路径规划：A*、Dijkstra、RRT-lite 算法原理及改进版本（如 RRT*）
        
    - 机械臂运动学：正运动学（FK）、逆运动学（IK）的基本思路与高效解法
        
- **工具**
    
    - ROS2 Humble/Iron/滚动更新版安装 & 基础操作
        
    - Gazebo/Ignition Gazebo 仿真环境搭建与模型导入
    
    - Docker 容器化部署实践（便于环境管理和团队协作）

## 🌿 阶段学习（按项目模块）

### 1. 机械臂控制（Week 3–7）

- 学习重点：
    
    - ROS2 控制器（ros2_control）机制及最新功能
        
    - MoveIt! 2 运动规划框架（支持 ROS2 的最新版本）
        
    - URDF/XACRO 模型构建与优化（关节/连杆/惯性参数）
        
    - 硬件接口与驱动开发（机器人硬件抽象层 HAL）
        
- 实践：
    
    - 在仿真中让机械臂完成关节轨迹跟随
        
    - 输出动作库（预设动作集合）及动作参数优化
    
    - 实现基于力/力矩传感器的柔顺控制（如适用）

### 2. 视觉抓取（Week 6–10）

- 学习重点：
    
    - OpenCV 4.x 基础（颜色识别、边缘检测、几何变换）
        
    - YOLOv8/YOLO-NAS 推理部署（轻量模型优化）
        
    - 手眼标定流程（像素坐标 → 机械臂坐标）及误差补偿
    
    - 3D 视觉基础（点云处理、深度相机应用）
        
- 实践：
    
    - 识别桌面上的目标 → 在 MoveIt 2 中生成抓取点 → 驱动机械臂抓取
    
    - 实现多目标识别与优先级抓取策略
    
    - 基于深度信息的抓取姿态优化

### 3. 移动底盘 & 路径规划（Week 8–12）

- 学习重点：
    
    - 底盘运动学模型（差速 / 麦轮 / 全向轮）
        
    - Nav2 (Navigation2) 框架最新特性与配置优化
    
    - SLAM 技术：cartographer_ros2、slam_toolbox、LIO-SAM（如适用）
        
    - 局部路径规划与避障算法（DWA、TEB、MPC）
        
- 实践：
    
    - 仿真小车在地图中移动到目标点
        
    - 添加动态障碍物，验证避障与重规划能力
    
    - 多机器人协同导航基础

### 4. 系统集成（Week 12–16）

- 学习重点：
    
    - 状态机设计（BehaviorTree.CPP、SMACH2）
        
    - 模块调度与容错（任务失败 → 重试 / 报错 / 降级处理）
        
    - ROS 2 多节点调度与消息同步（使用 Composition API）
    
    - 性能优化：实时性分析与瓶颈解决（使用 ROS2 性能工具）
        
- 实践：
    
    - 实现完整搬运任务（移动 → 抓取 → 运送 → 放置）
        
    - 集成机械臂、底盘、视觉，统一任务管理器
    
    - 实现系统级故障诊断与恢复机制

## 🌳 扩展阶段（Week 16+）

- **模块化末端**：学习电路 ID 识别与参数切换机制，实现末端执行器快速切换。
    
- **多模态控制**：理解如何接入 BCI/MR/语音接口（你负责接口设计，不必深做信号处理），并实现简单的人机交互场景。
    
- **智能决策**：学习基础的强化学习在机器人控制中的应用，如策略优化与自适应控制。
    
- **统筹升级**：能给每个小组提供接口规范和调度建议，成为"Glue Person"，并参与整体架构设计。
    
- **数字孪生**：了解机器人数字孪生概念与实践，实现虚实映射与协同。

## ⚡ 技术栈更新摘要

- **基础框架**: ROS2 Humble/Iron（替代旧版 ROS）

- **运动规划**: MoveIt! 2（全面支持 ROS2）
- **视觉算法**: YOLOv8/YOLO-NAS（更高精度与效率）
- **导航系统**: Nav2（全新架构的导航框架）
- **状态机**: BehaviorTree.CPP（更灵活的行为树实现）
- **部署工具**: Docker（简化环境配置与团队协作）
- **可视化**: Foxglove Studio（新一代机器人可视化工具）
