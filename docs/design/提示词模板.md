1. **一句话定义**
    
    - 直接解释该概念最小可验证的含义。
        
2. **体系定位**
    
    - 它在理论力学整体框架中的位置（属于运动学 / 动力学 / 静力学 / 分析力学等）。

    - 用直观语言或示意图帮助理解。
        
5. **常见错误 / 易混点**

6. **应用场景**
    
    - 工程、机械、机器人学、航天等实际问题中的对应案例。
        
7. **追问引导**
    
    - 如果我的问题不够完整，你要主动提问补充信息。
        
    - 如果有更深层次的相关内容，可以提醒我继续探索。

## 示例

**我问：什么是达朗贝尔原理？**

3. 公式与推导：写出 Σ(F − ma)·δr = 0，解释其由牛顿第二定律变形而来。
    
4. 几何图景：想象“惯性力”补上后系统好像静止。
    
5. 常见错误：惯性力并不是实际存在的力，而是数学上的假想力。
    
6. 应用场景：用于机械系统约束分析、拉格朗日方程的推导。
    
7. 追问引导：要不要我帮你展示它在“单摆”问题中的具体运用？
