# 底盘驱动板

---

## 底盘驱动板对比表

| 类型                        | 电压/电流范围    | 控制方式       | 是否闭环        | 成本 | 典型应用                 |
| --------------------------- | ---------------- | -------------- | --------------- | ---- | ------------------------ |
| **L298N / L9110S**    | 6–12V，<2A      | PWM+方向       | 否              | 极低 | 入门小车、低功率实验     |
| **BTS7960 / IBT-2**   | 12–24V，10–20A | PWM+方向       | 否              | 低   | 中型差速车、10kg 级平台  |
| **集成驱动+编码接口** | 6–24V，2–5A    | I²C/UART/SPI  | 支持速度闭环    | 中   | 教学车、ROS 入门平台     |
| **CAN 总线智能驱动**  | 24–48V，10–30A | CAN/RS485      | 支持速度/位置环 | 高   | 科研级全向轮/麦轮底盘    |
| **一体化轮毂模组**    | 24–48V，≥10A   | CANopen/Modbus | 完整三环控制    | 最高 | 商用机器人、复合型机器人 |

---

## 底盘驱动板选型流程

1. **确定电机规格**
   * 电机类型：直流/无刷直流（BLDC）
   * 电压范围（常见 12V/24V/48V）
   * 电流需求（持续电流/峰值电流）
2. **选择驱动控制方式**
   * 入门/低功率：PWM 控制
   * 高性能/抗干扰：CAN 总线
3. **判断是否需要闭环控制**
   * 若只要求开环速度控制 → L298N / BTS7960
   * 若要精确里程/速度反馈 → 集成驱动或 CAN 驱动
4. **结合成本和开发周期**
   * 成本敏感 → BTS7960（便宜但需自己写闭环）
   * 稳定性优先 → CAN 智能驱动 / 一体化模组

---

## 底盘驱动板选型结论

* **入门实验/教学平台（低功率、小车类）** ：选  **集成型驱动+编码接口** ，方便做 PID，快速集成到 Arduino/ROS 环境。
* **中型差速或麦轮平台（10~20kg 级）** ：选  **BTS7960/IBT-2** ，价格便宜，但需要额外处理闭环控制逻辑。
* **科研级/稳定运行需求** ：推荐  **CAN 总线智能驱动** ，可做速度、位置闭环，便于 ROS2 接入。
* **商用级机器人** ：选  **一体化轮毂模组** ，高度集成，稳定性最高，但价格较贵。
