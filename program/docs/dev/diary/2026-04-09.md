# 🐛 3. 问题与解决方案 (Issues & Solutions)

## 🔴 问题 1: WEB 页面没有展现雷达点位图

- 【**问题描述**】：WEB 页面打开后，LiDAR 面板只显示空画布或等待提示，无法看到 `/lidar_node/scan` 的点位图。最小复现案例：启动雷达节点后，在浏览器打开 WEB 页面，LiDAR 区域没有出现扫描点。
- 【**问题环境**】：Linux + ROS2 Humble + FastAPI + 浏览器前端页面。
- 【**问题分析**】：这次问题的核心原因是 WEB 端的数据源和真实 ROS2 雷达流没有打通，同时前端绘图缩放过大，导致即使拿到数据也可能被画到画布外。
- 【**问题状态**】：✅ 已解决
- 【**问题方案**】：让 WEB 直接订阅 ROS2 的 `/lidar_node/scan`，由后端返回最新 `LaserScan` 快照，再由前端按自适应比例绘制点位图。

```python
from sensor_msgs.msg import LaserScan

# 订阅 /lidar_node/scan
# 将 ranges / angle_min / angle_max / range_min / range_max
# 转成前端可直接绘制的 JSON
```

> 【代码解读】后端不再依赖 mock 雷达数据，而是直接消费 ROS2 发布的扫描消息；前端根据扫描最大可视范围自动缩放，保证真实点云落在画布内。

- 【**知识总结**】：通过这次修改，我学到了 WEB 展示机器人传感器时，最容易出问题的不是绘制本身，而是“数据链路是否真实接通”和“显示尺度是否和传感器量程一致”。
- 【**编码建议**】：建议下次遇到类似问题时，先检查浏览器拿到的到底是不是实时传感器数据，再检查画布缩放是否会把有效点画出边界。
